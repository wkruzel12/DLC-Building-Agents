# AI Agent Lab MVP

Build and score a three-stage Extract → Check → Flag agent over five fictional candidate resumes. Students revise instructions, inspect step-level output, compare agent decisions with an answer key, and see immutable scored attempts saved in Supabase. The current implementation uses Next.js, TypeScript, Tailwind, OpenAI Responses API, Supabase, and Vercel. Server-only case files keep the answer key inaccessible before runs. Scope excludes stakeholder chat, diagnose, portfolio, faculty dashboard, and D2L. See README.md for setup and API contract.
